# 🚀 Uban 終極桌面小豬：【賽博伴侶進化計畫】

## 1. 專案背景與目標
目前桌面小豬（Desktop Pet）已具備基礎的數據顯示與互動能力。為了進一步提升長輩的「使用黏著度」與「情感認同」，我們提議結合市場上最成功的互動元素，將小豬轉化為一個具備靈魂的「數位伴侶」。

## 2. 三位一體設計理念 (The Trinity Concept)

### A. 菲比啾比 (Phoebe Chubby) - 【魔性靈魂】
*   **關鍵元素**：洗腦語法、情緒反饋、性格變化。
*   **實作內容**：
    *   **疊字語法系統**：小豬說話會帶有「啾比...」、「...嚕嚕」等後綴，建立鮮明角色個性。
    *   **動態情緒看板**：UI 介面模擬養成遊戲，顯示親密度與飢餓值。
    *   **反差萌反應**：當長輩達成目標或餵食時，觸發誇張的洗腦音效與全螢幕視覺特效。

### B. Pokémon GO - 【空間互動】
*   **關鍵元素**：AR 體感、投擲回饋。
*   **實作內容**：
    *   **Flick-to-Feed (滑動投餵)**：拋棄按鈕，改用「向上滑動」的手勢將蘋果拋向小豬，並具備拋物線物理模擬。
    *   **Simulated AR (輕量化 AR)**：開啟相機作為背景，讓小豬「坐」在長輩家中的餐桌、客廳。
    *   **空間抓取**：長輩可以「拎起」小豬放入 AR 空間中的不同位置。

### C. Pikmin Bloom - 【走路遠征】
*   **關鍵元素**：步數轉化、收集要素、散步日誌。
*   **實作內容**：
    *   **小豬遠征隊**：長輩散步時，小豬會在後台「撿拾」隨機道具（種子、裝飾品）。
    *   **每日冒險日誌**：每天結束後產出一張可愛的圖卡，總結今日小豬跟長輩一起去過的地方。

## 3. 分階段開發路徑 (Phased Roadmap)

### 第一階段：【養成基礎】 (1-2 週)
- [ ] 實作 `PetProfileScreen` 賽博養成風格 UI。
- [ ] 實作「滑動投餵蘋果」物理手勢。
- [ ] 整合「菲比語」隨機對話系統。

### 第二階段：【沈浸互動】 (2-4 週)
- [ ] 實作「輕量化 AR」相機背景模式。
- [ ] 加入「進食」、「飽嗝」、「撒嬌」等專屬音效。
- [ ] 開發「親密度」系統與等級視覺演化（例如：小豬長大或戴帽子）。

### 第三階段：【生態連結】 (4 週以上)
- [ ] 實作「家屬空投禮物」跨 App 連動。
- [ ] 串接 Google Fit / HealthKit 達成「皮克敏式」的道具撿拾邏輯。

## 4. 預期價值
1.  **使用者面**：將健康監測轉化為「養寵物」的樂趣，減少長輩被監控的壓力。
2.  **子女面**：提供一個具備話題性的「社交切入點」，子女可以透過空投禮物與長輩互動。
3.  **商業面**：養成系統可作為未來數位資產（外觀造型、道具）的擴展基礎。
