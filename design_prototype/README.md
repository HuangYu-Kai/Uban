# Uban 長輩端 UI 設計原型（HTML 互動稿）

純前端互動設計稿，作為 Flutter 長輩端 UI 改造的**視覺與互動基準**。
**只是設計示意：資料、照片、視訊畫面皆為假資料，不含任何後端/功能接線。**

## 開啟方式

### 系統展示台（建議展示入口）

建議從專案根目錄啟動簡易靜態伺服器後開啟（比直接使用 `file://` 更穩定）：

```text
design_prototype/showcase.html
```

展示台依照「長輩的一天」的故事流程切換畫面，包含問題情境、AI 互動、GPS、求助、家屬回應、生活紀錄、系統架構／特殊技術與結語。一般段落會同步控制長輩端與家屬端原型；可切換成只看單一角色，也可以使用全螢幕。

### 原型單獨開啟

- `index.html`：長輩端登入流程、五個分頁、新聞、寵物、語音／視訊通話與浮層互動。
- `family.html`：家屬端首頁、互動、資料、GPS 地圖、警示中心、健康趨勢與通話房。

兩份原型仍可獨立開啟，展示台只透過受控的瀏覽器訊息切換畫面，不會接上正式後端。

## 檔案
- `index.html` — 畫面結構（登入流程＋長輩端五分頁＋新聞/通話房/各式浮層）
- `ui.css` — 設計系統（teal 主色、毛玻璃、適老化大字、小豬舞台、動效）
- `ui.js` — 互動（等比縮放、分頁切換、小豬餵食/走動、聊天橡皮筋、祝福圖模板…）
- `showcase.html` — 系統展示台入口，依影片段落同步切換兩個角色原型
- `showcase.css` — 展示台外殼、段落導覽、技術架構頁與響應式版面
- `showcase.js` — 段落資料、畫面對應、雙端 iframe 控制與播放導覽
- `img/`、`fonts/` — 圖片與字體資產

## 設計重點
- **等比縮放**：內容鎖參考寬 390px 再整體 `transform:scale()`，所有裝置版面一致、不截字；另含平板基礎適配。
- **狀態列/輸入列遮底**：捲動時內容不穿透狀態列、聊天輸入列與固定標題。
- **動效**：首頁大卡「寶石鑲入」入場、天氣光暈、聊天拖曳橡皮筋（泡泡拉開回彈）、導覽列彈簧指示。
- **祝福圖三模板**：日出／蓮花／鯉魚，可切換場景與祝語。
- 全程相容淺／深色、通話/新聞深底，並尊重系統「減少動態」偏好。
