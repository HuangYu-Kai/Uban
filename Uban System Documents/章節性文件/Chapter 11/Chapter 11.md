# 第十一章 操作手冊

本章說明如何把 Uban 安裝到使用者的電腦與手機：先在 Windows 電腦執行安裝程式 Uban_Setup_1.0.0.exe，再透過 USB 將 Android App 安裝到實體手機或 Android Studio 模擬器。App 開啟後的各項功能操作，請參閱第十二章使用手冊。Uban 的後端服務已部署在正式站，電腦上不需要另外安裝伺服器，只要手機或模擬器能連上網路即可。

## 11-1 系統元件與安裝環境

表 11-1-1 彙整 Uban 安裝檔的基本資訊，以及電腦端、手機端的環境需求。

### 表 11-1-1 系統安裝元件

| 屬性 | 內容 |
| :---: | :--- |
| **元件名稱** | Uban 安裝程式（Uban_Setup_1.0.0.exe）與 Uban Android App（Uban.apk） |
| **版本** | 1.0.0 |
| **軟體種類** | Windows 安裝程式（Inno Setup 製作）；Android 行動應用程式（APK） |
| **使用對象** | 長輩、家屬與照護者、評審人員 |
| **支援語言** | 繁體中文 |
| **電腦端需求** | Windows 10 或 Windows 11<br>安裝時不需要系統管理員權限<br>電腦可連接網路，並備有可傳輸資料的 USB 線 |
| **手機端需求** | Android 8.0 以上的實體手機，或 Android Studio 模擬器（Android 8.0 以上）<br>手機需連上網路，App 會連到正式站伺服器<br>Uban 僅提供 Android 版，不支援 iPhone／iPad（iOS） |
| **安裝檔內容** | Uban_Setup_1.0.0.exe 安裝後，會在安裝資料夾放入：<br>Uban.apk（Android App）<br>platform-tools（adb 工具）<br>install_app.ps1（安裝到手機的腳本）<br>安裝說明 |
| **內容分級** | 普遍級 |

Uban 是 Android 手機 App。App 使用了來電畫面（CallKit）、推播（FCM）、LINE 登入（LINE SDK）與計步器等手機專用套件，這些套件無法在 Windows 桌面環境執行，所以本專題沒有提供 Windows 桌面版，而是以 Android 安裝檔（APK）作為交付物。Uban 僅提供 Android 版，不支援 iPhone／iPad（iOS）。Windows 安裝程式的用途，是把 APK 與 adb 工具放到電腦上，再藉由 USB 偵錯把 App 一次裝進手機或模擬器，讓使用者不必自行準備開發環境。

## 11-3 安裝 App 到手機

電腦端安裝完成後，Uban 提供三種方式把 App 裝到手機。方法一使用 USB 連接實體手機，為建議方式；方法二適用於 Android Studio 模擬器；方法三是前兩種都無法使用時，手動傳送 APK 安裝。本節截圖取自 Android Studio 模擬器（英文介面），各品牌手機的選單名稱與位置不同，請依表 11-3-1 找到對應路徑；實際名稱以手機畫面為準。

### 表 11-3-1 各品牌開啟開發人員選項與 USB 偵錯的路徑

| 品牌 | 開啟開發人員選項 | USB 偵錯位置 |
| :---: | :--- | :--- |
| **Google Pixel／原生 Android** | 設定 → 關於手機 → 連點「版本號碼」7 次 | 設定 → 系統 → 開發人員選項 → USB 偵錯 |
| **Samsung Galaxy** | 設定 → 關於手機 → 軟體資訊 → 連點「版本號碼」7 次 | 設定 → 開發人員選項（位於設定清單最下方）→ USB 偵錯 |
| **小米／Redmi／POCO（HyperOS、MIUI）** | 設定 → 關於手機 → 連點「HyperOS 版本」或「MIUI 版本」約 7～10 次 | 設定 → 其他設定（部分版本為「系統設定」）→ 開發人員選項 → USB 偵錯 |
| **OPPO／realme（ColorOS、realme UI）** | 設定 → 關於手機（部分機型在「版本」內）→ 連點「版本號碼」7 次，並輸入螢幕鎖定密碼 | 設定 → 其他設定（舊版為「系統設定」）→ 開發人員選項 → USB 偵錯 |
| **vivo（Funtouch OS、OriginOS）** | 設定 → 系統管理 → 關於手機 → 版本資訊 → 連點「軟體版本」7 次 | 設定 → 系統管理 → 開發人員選項 → USB 偵錯 |
| **ASUS** | 設定 → 系統 → 關於手機 → 軟體資訊 → 連點「版本號碼」7 次 | 設定 → 系統 → 開發人員選項 → USB 偵錯 |
| **其他品牌** | 在「設定」上方的搜尋欄輸入「版本號碼」或「開發人員」，直接跳到該項目 | 在「設定」搜尋欄輸入「USB 偵錯」 |

開啟 USB 偵錯後，若連接不認識的電腦會有資安風險；安裝完成後可關閉 USB 偵錯，不影響 Uban 使用。

### 表 11-3-2 方法一：以 USB 連接實體手機操作說明

| 步驟 | 說明 |
| :---: | :--- |
| **1. 開啟開發人員選項** | 依表 11-3-1 的品牌路徑，在「關於手機」連續點選「版本號碼」7 次，依提示輸入螢幕鎖定密碼。<br>模擬器英文畫面對應：Build number＝版本號碼、Developer options＝開發人員選項、USB debugging＝USB 偵錯。 |
| **2. 開啟 USB 偵錯** | 依表 11-3-1 的品牌路徑進入「開發人員選項」，開啟「USB 偵錯」（USB debugging）。 |
| **3. 連接電腦** | 用 USB 線連接手機與電腦，USB 模式選擇「檔案傳輸」。請使用可傳輸資料的 USB 線，部分線材只能充電。 |
| **4. 允許 USB 偵錯** | 手機會跳出「允許 USB 偵錯嗎？」，勾選「一律允許這台電腦」並按「允許」。 |
| **5. 執行安裝** | 在安裝完成頁保持勾選「立即將 Uban 安裝到手機」後按「完成」；或之後從「開始」功能表執行「安裝 Uban 到手機」。會開啟標題為「Uban 手機安裝程式」的視窗，程式自動偵測手機並顯示「正在安裝到 〈手機型號〉（〈序號〉），約需 30 秒…」。 |
| **6. 確認安裝成功** | 視窗顯示「安裝成功：〈手機型號〉」，以及「Uban 已安裝並開啟，請在手機上依畫面完成註冊或登入。」手機上會自動開啟 Uban，主畫面可看到 Uban 圖示。依視窗提示按 Enter 鍵關閉視窗。 |

## 11-5 常見問題與解除安裝

表 11-5-1 列出安裝時最常遇到的四個問題與處理方式。

### 表 11-5-1 常見問題與處理方式

| 問題 | 處理方式 |
| :---: | :--- |
| **Q1. 程式偵測不到裝置？** | 更換 USB 線（有些線只能充電）或換一個 USB 埠。<br>安裝手機廠商的 USB 驅動程式（如 Samsung、ASUS、Xiaomi、OPPO 官網下載）。<br>手機 USB 模式改為「檔案傳輸 (MTP)」。<br>確認 USB 偵錯已開啟，且手機上已按過「允許」；可關閉後重開 USB 偵錯再試。<br>處理完後在安裝視窗按 Enter 重新偵測。 |
| **Q2. 手機上已有簽章不同的舊版 Uban？** | 安裝視窗會偵測到並顯示「手機上已裝有簽章不同的舊版 Uban，必須先移除才能安裝。」，接著詢問「要移除舊版並重新安裝嗎？(Y/N)」。移除會清除舊版的本機資料（伺服器上的帳號與資料不受影響），請確認後再輸入 Y。 |
| **Q3. 如何解除安裝？** | 電腦端：Windows 設定 →「應用程式」→「Uban」→「解除安裝」，或「開始」功能表 Uban →「解除安裝 Uban」。<br>手機端：長按 Uban 圖示 →「解除安裝」。電腦端解除安裝不會移除手機上的 App。 |
| **Q4. 可以安裝在 iPhone 嗎？** | 不支援。本專題僅提供 Android 安裝檔（APK），iOS 裝置（iPhone、iPad）無法安裝。 |
