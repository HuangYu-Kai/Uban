Uban AI 跨世代感知照護系統 - 安裝說明
國立臺北商業大學 資訊管理系 第115207組
==================================================

Uban 是 Android 手機 App。本安裝程式會把安裝工具放到這台電腦，
再透過 USB 將 Uban 安裝到您的手機或模擬器。
後端服務已部署在正式站，電腦上不需要另外安裝伺服器。

一、系統需求
--------------------------------------------------
1. 電腦：Windows 10 或 Windows 11
2. 手機：Android 8.0 以上，並備有可傳輸資料的 USB 線
   或 Android Studio 模擬器（Android 8.0 以上）
3. 網路連線（App 需連到正式站伺服器）

二、方法一：以 USB 連接實體手機（建議）
--------------------------------------------------
1. 開啟開發人員選項：
   設定 -> 關於手機 -> 連續點選「版本號碼」7 次
   （部分品牌在「軟體資訊」底下），依提示輸入螢幕鎖定密碼。
2. 開啟 USB 偵錯：
   設定 -> 系統 -> 開發人員選項 -> 開啟「USB 偵錯」。
3. 用 USB 線連接手機與電腦，USB 模式請選「檔案傳輸」。
4. 手機會跳出「允許 USB 偵錯嗎？」，勾選「一律允許這台電腦」並按「允許」。
5. 執行 Uban_Setup，結束頁保持勾選「立即將 Uban 安裝到手機」後按「完成」；
   或之後從開始選單執行「安裝 Uban 到手機」。
6. 視窗顯示安裝成功後，手機上即可看到 Uban 圖示。

三、方法二：Android Studio 模擬器
--------------------------------------------------
1. 先啟動模擬器，等進入手機主畫面。
2. 再執行「安裝 Uban 到手機」，程式會自動安裝到該模擬器。

四、方法三：手動傳 APK 安裝
--------------------------------------------------
1. 開啟開始選單的「Uban 安裝檔資料夾」，找到 Uban.apk。
2. 以 USB 複製、雲端硬碟或通訊軟體把 Uban.apk 傳到手機。
3. 在手機上點開 Uban.apk；若出現「禁止安裝不明來源應用程式」，
   依畫面指示允許該來源（例如檔案管理員或瀏覽器）後再安裝。

五、首次開啟需要授權的權限
--------------------------------------------------
請在提示時按「允許」，否則部分功能無法使用：
- 麥克風、相機：語音通話、視訊通話與語音助理
- 通知：提醒、來電與家人訊息
- 位置：位置分享與安全守護
- 身體活動：計步
- 顯示在其他應用程式上層／全螢幕通知：來電畫面
- 電池最佳化例外：避免背景提醒被系統中斷

六、常見問題
--------------------------------------------------
Q1. 程式偵測不到裝置？
- 更換 USB 線（有些線只能充電）或換一個 USB 埠。
- 安裝手機廠商的 USB 驅動程式（如 Samsung、ASUS、Xiaomi、OPPO 官網下載）。
- 手機 USB 模式改為「檔案傳輸 (MTP)」。
- 確認 USB 偵錯已開啟，且手機上已按過「允許」；可關閉後重開 USB 偵錯再試。

Q2. 手機上已有簽章不同的舊版 Uban？
- 腳本會偵測到並詢問是否移除舊版。移除會清除舊版的本機資料，
  請確認後再同意。

Q3. 如何解除安裝？
- 電腦端：Windows 設定 -> 應用程式 -> Uban -> 解除安裝，
  或開始選單 Uban -> 解除安裝 Uban。
- 手機端：長按 Uban 圖示 -> 解除安裝（電腦端解除安裝不會移除手機上的 App）。
