# 第 5 章　主動關懷與長期記憶（75 秒・正午）

> 依 `06-storyboard-brief.md` 起草，格式照 `04-shotcraft-guided.md` 第 3 章樣本。
> **本章要讓觀眾記住：** 小嘎不只等人來問，它會先開口關心；阿公說過的事它記得，下次聊到就接得上。

- 時段與底色：正午。4→5 從「關」字的門框穿進來時還是早上 8 點的暖白，5-2 選擇器一格一格往後轉，底色跟著走到正午的明亮暖白（全章最亮、陰影最短）；章尾開始偏向午後的 mint，交給第 6 章。
- 節奏：全片的呼吸章。只用 3 個主角鏡，鏡頭幾乎只做緩推與平移，配樂抽掉鼓、留鋼琴與和聲；轉場只用 R 元素接力與 C 連續運鏡（本章 W／P／H／擦除配額都是 0）。
- 章標籤：`05 主動關懷`。稱謂：長輩「阿公」、家屬「兒子」。
- 小嘎說的話一律照後端的真實句型改寫（早安問候帶天氣與一個小問題；家屬留言用固定句型轉述），不替它編新功能。

## 風險

1. **久坐提醒目前不在程式裡。** README 的主動關懷寫著「早晨問候、服藥提醒、久坐提醒」，但現在的 `uban-api/services/proactive_care.py`（2026-10-28 改版）只依「沉默超過設定的分鐘數」觸發，話題依序是家屬留言 → 接著今天聊過的事 → 早上 7–10 點早安 → 興趣、天氣、身體、睡眠；全專案找不到久坐偵測。所以 5-2 沒有放「久坐提醒」，改放真實存在的「兒子留言」「接著聊」「聊聊興趣」。若使用者堅持要久坐，需要先確認是否另有實作；沒有的話不能畫成已完成功能。
2. **「主動問起」的界線。** 後端主動開口時只會接「今天」聊過的話；跨天的長期記憶是在阿公開口聊天時被檢索出來的。所以 5-12 寫成「阿公先說孫子要來 → 小嘎想起上禮拜的考試」，而不是小嘎憑空跨天主動問。04 對照表那句「上次你說孫子要考試，結果怎麼樣？」改成這個版本，語意相同但符合實際行為。
3. **「魚你聊聊」池塘不能出現。** 舊分鏡的荷葉池塘（`zen_pond/`）已不掛在 App 導覽上，是進不去的畫面，本章完全不用。
4. **`document-typewriter-reveal` 原生是暗場。** 卡片的舞台是極光暗場、窗口像一盞燈；正午時段要改成亮場，窗口靠陰影與亮邊和背景分開。要實測窗口在亮底上還分不分得出來；分不出來就把背景壓到偏暗的暖灰，但不能暗到像換了時段。卡片的強調色（游標、內緣線）統一換成 App 主綠。
5. **`doc-park-left-pill-deal` 的字幕長度。** 卡片的「逐字加深」是照原文句長調的，換成中文三句後要重調；三張膠囊的間隔不能壓短，否則字幕一閃就沒了。膠囊寬度寫死在 480 寬畫布的比例，放大到 1080p 時要整組等比換算。
6. **`picker-carousel-feature-cycle` 的字數。** 每列「時間＋項目」最長 9 個字，放大到 ≥ 60 px 後要確認單行不超過選擇器寬度（卡片要求縮字號、不能換行）；5 拍已是卡片的上限，不能再加項目。
7. **小嘎的稱呼。** 後端規定沒有資料指定時不准叫「阿公」，截圖前要先在測試帳號把稱呼設成「阿公」，否則實際畫面會是「您」，和字卡對不上。
8. **5-8 是自製示意，不是 App 畫面。** 要讓觀眾讀得出「這是說明」：用和 App 截圖不同的扁平版式，不加手機外框。
