# 專題展長片（expo-video）設計文件

這個資料夾只放文件，是 `expo-video/`（本機 Remotion 專案）的分鏡、量產規則與工作記憶的備份。和同分支的 `video/uban-saas`（廣告影片）是兩個獨立專案，互不相干。

- `docs/designs/`：00–08 製作文件（07 是量產共同規則，08 是素材清單）、`storyboard/`：各章分鏡（第 3 章分鏡在 04 檔）。
- `audio/`、`chapters/`：配樂與早期章節實驗的筆記。
- `memory/`：AI 協作的工作記憶（進度、使用者裁示、接手點）；`project_expo_video.md` 檔尾的「收工狀態」是最新接手點。

- `ACCOUNTS.md`：拍片專用測試帳號（含密碼）、模擬器登入指令、已建的假資料。

程式碼與素材（Remotion 專案本體、截圖、影片輸出）不在這裡。
