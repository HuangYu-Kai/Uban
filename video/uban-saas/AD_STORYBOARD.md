# Uban 廣告分鏡說明

> 方向 A「你多久才知道？」為主，加入方向 B 的打卡鼓勵來回、每日一問、小豬共養。
> 30 fps。配樂 120 BPM（1 拍 = 15 影格），所有切點都落在拍點上。
> App 畫面全部是素材包 `02_螢幕錄影` 的實機錄影（暗色模式），沒有用程式畫的介面。

| 成品 | Composition | 規格 | 時間軸 | 版面 |
|---|---|---|---|---|
| `out/ad_60s.mp4` | `Ad60` | 1920×1080、60 秒 | `TL60` | `GEO.wide` |
| `out/ad_15s.mp4` | `Ad15` | 1920×1080、15 秒 | `TL15` | `GEO.wide` |
| `out/ad_60s_vertical.mp4` | `Ad60V` | 1080×1920、60 秒 | `TL60` | `GEO.tall` |

三支共用同一套鏡頭程式（`src/Ad.tsx`），只換時間軸與版面。

## 直式版（9:16）怎麼重新構圖

時間點與 60 秒橫式版完全相同，每個鏡頭的位置另外排過（`GEO.tall`），不是從橫式裁切。

| 鏡頭 | 橫式 | 直式 |
|---|---|---|
| 開場、警報、長輩、小嘎、小豬 | 手機在一側，文字在另一側 | 文字在上方（y 220–560），手機置中在下方並放大 |
| 警報的情境摘要字卡 | 標題下方、手機左側 | 標題與手機之間，寬 900 |
| 小嘎的長輩原話與聲波卡片 | 標題下方、手機左側 | 標題與手機之間 |
| 打卡與鼓勵（雙機） | 兩機在左右兩端，標題在中間 | 標題在上，兩機左右並排放大，聲波在兩機下方 |
| 每日一問（雙機） | 兩機在右側前後錯位，文字在左 | 文字與引言在上，兩機左右並排 |
| 小豬五階段 | 標題下方、手機右側 | 標題與手機之間橫排 |
| 結尾三個重點 | 橫排 | 直排 |
| 「App 畫面皆為實機錄影」 | 上緣 y 30 | y 150（避開手機平台的上方介面） |

雙機鏡頭在直式採左右並排而不是上下排列：上下排列時每支手機只能約 760 高，螢幕內容太小看不清楚；左右並排可以到約 970 高。

## 怎麼改

- **顏色、文案**：`src/Ad.tsx` 開頭的 `C` 與 `COPY`（15 秒版有差異的句子在 `TL15.COPY`）。
- **時間點、錄影片段、聲音**：`TL60`（60 秒橫式與直式共用）與 `TL15`，各有 `T` 鏡頭起訖、`CLIPS` 錄影片段、`CUE` 動作影格、`MUSIC`／`SOUNDS`。
- **位置與大小**：`GEO.wide`（橫式）與 `GEO.tall`（直式）。
- **配樂與音效**：`node scripts/make_audio.mjs` 重新合成；BPM 與每支配樂的收尾秒數在該檔開頭的 `MUSICS`。改了結尾鏡頭的起點，要同步改對應的 `endingAt`。
- **重新算圖**（一行一支）：

```bash
npx remotion render src/index.ts Ad60 out/ad_60s.mp4 --browser-executable="C:/Program Files/Google/Chrome/Application/chrome.exe" --concurrency=4 --crf=17
```

```bash
npx remotion render src/index.ts Ad15 out/ad_15s.mp4 --browser-executable="C:/Program Files/Google/Chrome/Application/chrome.exe" --concurrency=4 --crf=17
```

```bash
npx remotion render src/index.ts Ad60V out/ad_60s_vertical.mp4 --browser-executable="C:/Program Files/Google/Chrome/Application/chrome.exe" --concurrency=4 --crf=17
```

（同時算圖數設 8 會中途失敗，4 穩定。60 秒版一支約 8–10 分鐘，15 秒版約 2 分鐘。）

- **影格總覽**：`python scripts/make_overview.py <影片> <輸出圖> [間隔秒數] [每列幾格] [每格寬度]`。

## 與事實對齊的注意事項

- 實機警報標題是「偵測到長時間無活動」，不是「跌倒」，所以開場文案寫「倒在地上」，全片沒有出現「跌倒」兩個字。
- 「情境摘要」沒有實機畫面，以手機旁的字卡呈現並標示示意內容，不放進手機螢幕。
- 沒有「家人送點心」的錄影，小豬段的畫面是餵胡蘿蔔與「全家一起走」卡。
- 錄影中出現組員真實姓名（周宇璿、童柏祐）、家人鼓勵的真實聲音，以及組員入鏡的監視畫面（沒有露臉）。
- 沒用到含住址、含位置的兩支錄影，也沒用視訊錄影；畫面上沒有伺服器網址、帳號或金鑰。
- 長輩首頁錄影裡有當天的新聞頭條圖片與標題（App 的今日頭條）。
